
## 작업 (코드캔버스 푸터)
**요청:** 코드캔버스 앱에 aklabs-footer 푸터 추가
**작업 내용:** css/footer.css 신규, index.html에 푸터 추가, 편집 영역 높이에서 푸터 높이(36px)를 빼도록 layout.css·responsive.css 수정. 공유 보기(view-mode)·인쇄에선 숨김. 모바일은 헤더가 두 줄이 되어 높이가 달라지므로 body를 세로 flex로 바꿔 푸터가 밀리지 않게 함
**결과:** 완료 (1024·375 폭에서 푸터가 맨 아래에 딱 붙고 가로 넘침 없음, 링크 높이 34px, 글자 14px 확인). 커밋·푸시는 승인 대기
**해결한 오류:** 모바일에서 푸터가 화면 아래로 15px 잘림 → 헤더 높이가 변수(56px)보다 커서(71px) → 편집 영역이 남는 높이를 채우게 변경
**확인 방법:** ①코드캔버스를 열고 ②화면 맨 아래 AKLABS 띠와 두 링크가 보이는지 ③폰 크기로 줄여도 잘리지 않는지 확인
