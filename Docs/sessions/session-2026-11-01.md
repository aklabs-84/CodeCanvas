**남은 일 설명:** 이번엔 "찾아서 제안"까지만 했어요. 어떤 걸 고칠지 정해 주시면 그때 고쳐요.

## 작업 (미리보기 보정·제출 서버·보안 수정 구현)
**요청:** 점검에서 나온 개선안을 전부 순서대로 진행 + AI 코드 사전 안내 + alert/인쇄/버튼 동작 확인, 기존 기능 유지 확인
**작업 내용:** css/layout.css(기기 미리보기 왼쪽 잘림·안내 배너 스타일), js/preview.js(실행 전 점검 배너, 폼·링크·파일 불러오기 실패·이중 스크롤 진단, entryCode 전달, 메시지 출처 확인, 공유 링크 격리 실행), index.html(전체화면 등 권한 추가), js/editor.js(module/importmap 스크립트 보존), api/submit.js(허용 필드·길이·https·Origin 확인·일반 오류 문구), js/projects.js(스튜디오 제목·PRD 특수문자 무력화)
**결과:** 완료. 브라우저에서 실행·기기 전환·콘솔·에러 탭·탭 분리/통합 왕복·제출 버튼·entryCode 전달 확인, 제출 서버는 모의 서버로 13가지 경우 시험
**해결한 오류:** 미리보기 스크립트 문법 오류 → 템플릿 문자열 안의 정규식 `\/\/`가 주석으로 해석됨 → 정규식 없이 문자열 비교로 교체
**남은 일:** 편집 화면은 아직 allow-same-origin 유지(별도 미리보기 주소가 근본 해결), <html> 태그 속성 보존은 미구현, index.html.bak·js/editor.js.backup 정리 여부 결정
**확인 방법:** ① 주소 끝에 ?entryCode=테스트 를 붙여 열기 ② 제미나이 키가 들어간 코드를 붙여넣고 실행 → 위쪽에 노란 안내 상자가 뜨는지 ③ 링크·폼 버튼을 눌러 콘솔에 안내가 뜨는지
**남은 일 설명:** 지금은 내가 직접 만드는 화면에서 붙여넣은 코드가 코드캔버스와 같은 집에서 실행돼요. 남의 공유 링크는 이미 따로 분리했어요. 완전히 분리하려면 미리보기 전용 주소를 하나 더 만들어야 해서 큰 작업이라 제안만 남겨 둬요.

## 제출 방식 개선 조사 (로그인 없이 링크 제출)
**요청:** 클래스로그AI 연동 제출이 코드(text)로 가고 잘림 → 로그인 없이 링크로 제출 가능한지
**작업 내용:** js/app.js 제출 버튼, projects.js saveToCloud/pushToCloud, api/submit.js 확인. 비로그인은 text, 로그인은 link로 가는 구조. 공유 링크는 Supabase projects 테이블(user_id 필요)에 저장해야 해서 비로그인은 불가.
**결과:** 방법 제안(서버가 대신 저장) — 사용자 승인 대기
**구현:** api/submit.js에 손님 저장(guestStorage/saveGuestProject/deleteGuestProject) 추가, js/app.js는 비로그인 시 guestCode 함께 전송. 환경변수 SUPABASE_URL·SUPABASE_SERVICE_ROLE_KEY(기존)+CODECANVAS_SB_GUEST_USER_ID(신규). URL에 프로젝트 ref가 없으면 손님 저장 건너뜀.
**결과:** 모의 테스트 4건 통과(설정 없음/다른 프로젝트→코드 제출, 정상→링크 제출, 제출 거절→손님 앱 삭제). 아직 커밋·푸시 안 함, 실제 배포 확인 필요.
**남은 일:** Supabase에서 손님 계정 만들기 → Vercel에 CODECANVAS_SB_GUEST_USER_ID 추가 → 배포 후 실제 제출 확인
**확인 방법:** ①Supabase Authentication→Users에서 손님 계정 만들고 UID 복사 ②Vercel 환경변수에 CODECANVAS_SB_GUEST_USER_ID 추가 후 재배포 ③로그아웃 상태로 ?entryCode=테스트 주소를 열고 제출 ④보드에 링크로 올라왔는지 확인
